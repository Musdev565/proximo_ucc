# Prompt de démarrage (à coller à chaque nouvelle session de l'agent)

```
Tu travailles sur le projet Proximo UCC. Lis d'abord AGENTS.md, puis docs/PROGRESS.md,
puis docs/workflow/00-workflow.md.

Ta mission de cette session : la tâche {Txx} (fiche : docs/workflow/tasks/{Txx-...}.md).
Fais UNIQUEMENT cette tâche. Respecte les interdits d'AGENTS.md, en particulier :
plan 2D (jamais de 3D), rien hors docs/specs/, une seule tâche.

Avant de coder : résume en 5 lignes ce que tu vas faire et pose-moi tes questions s'il y en a.
Quand tous les critères d'acceptation sont vrais : coche la tâche dans docs/PROGRESS.md,
fais le commit prévu, puis ARRÊTE-TOI avec un compte rendu court. Ne commence pas la tâche suivante.
```

Variante pour reprendre après une interruption :
```
Relis AGENTS.md et docs/PROGRESS.md. Dis-moi où en est la tâche {Txx} (ce qui est fait, ce qui reste),
puis continue uniquement cette tâche.
```
